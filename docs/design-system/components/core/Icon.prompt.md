A Heroicons v2 glyph that inherits `currentColor`.

```jsx
<Icon name="shopping-cart" size={24} label="Cart" />
<Icon name="gift" size={20} style={{ color: "var(--gold-600)" }} />
<Icon name="star" set="solid" size={16} />
```

Outline 24 (1.5px stroke) is the default everywhere; solid only for rating stars, favourited hearts and success confirmations. Set `basePath` to reach `assets/icons` from your page.
