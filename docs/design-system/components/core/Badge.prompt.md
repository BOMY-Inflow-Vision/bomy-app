A pill label — product categories, brand categories, account role.

```jsx
<Badge>Snacks</Badge>
<Badge variant="reward">Member</Badge>
<Badge variant="neutral">seller_owner</Badge>
```

Default is `accent` (red-50 / red-700), matching the catalogue chips on the products and brands grids. Use `reward` for membership, `success`/`warning`/`danger` for state — for order and product lifecycle state use `StatusPill` instead.
