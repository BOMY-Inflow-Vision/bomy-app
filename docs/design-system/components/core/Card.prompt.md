The default content surface — white card, 1px sand border, warm shadow-sm.

```jsx
<Card>
  <CardHeader>
    <CardTitle>A curated marketplace</CardTitle>
    <CardDescription>Every brand earns its place.</CardDescription>
  </CardHeader>
  <CardContent>…</CardContent>
</Card>
```

Padding is 24px on every slot. Pass `interactive` when the whole card is a link so it lifts on hover. Never add a coloured left border.
